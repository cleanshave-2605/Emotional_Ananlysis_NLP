# Emotional_Ananlysis_NLP
This is a repository created to house the files for the project "Emotional Classification for Hindi Language with Intensity" as a part of course CS626 at IIT Bombay.

The core paper we are referring to is called "Emotion recognition in Hindi text using multilingual BERT transformer" by Tapesh Kumar et. al. It has been added to this repository.

The project is using the BHAAV dataset which is also added in this repository.

**ABSTRACT**
Regular sentiment analysis of text classifies the texts into either Positive, Negative or neutral tones. However, these sentiments are umbrella terms for the multitude of emotions that come under them. Emotional analysis and recognition deals with these emotions. A lot of work has been done in the field of Emotional Analysis for English, but it is still a sparse area to be explored in more Indic languages that follow a more SOV order. This work makes use of the BHAAV dataset to perform emotional analysis for Hindi language. We are using multiple models to perform the classification - Vanilla Logistic Regression, Simple Neural Network, Convolution Neural Network, LSTM based model and multilingual BERT transformer. We compare the performances of these models with modern day Chat bots like ChatGPT, Claude, Gemini, Mistral-7B and LLAMA-3.

Additionally, most emotional analysis gives the emotion of the text, but fails to provide the intensity of the expression. For example, being jolly, happy and exhilirated are 3 different levels of joy and hence have different intensities. This work shall also model intensities to create a more granular classification of emotions.
